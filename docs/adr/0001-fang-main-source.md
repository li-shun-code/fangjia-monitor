# ADR-0001: 房天下为主数据源，链家为小区人气补充，安居客弃用

日期：2025-11-23
状态：已接受

## 背景

需求：重庆房价监控大屏（区县 + 小区级，含二手房房源浏览），数据免费可得、可在 GitHub CI 里无人值守采集。

候选：安居客行情站、链家（PC/移动）、房天下（移动/PC）、鸥维数据（付费）。

实测结论：

- **安居客全线反爬**（58.com antibot JS 挑战页），CI 不可采 → 弃用。
- **链家 PC**（cq.lianjia.com/xiaoqu、ershoufang）跳验证码 → 弃用；**链家移动端人气小区榜** `m.lianjia.com/cq/bangdan/ibd3/` 服务端渲染可采（TOP30 小区：在售/在租/关注/均价）→ 仅作补充。
- **房天下移动端**全链路可直连：城市房价地图（37 区县均价/环比/同比）、区页（商圈 + 小区涨跌榜）、按小区过滤的二手房列表（`?projcodes=<xid>`）、房源详情（相册图直链）。families 页 UTF-8、esf 页 GBK，需按 charset 嗅探解码。
- 鸥维数据 ¥499/年 → 排除。
- 所有站点的历史走势页均为 JS 注入，拿不到服务端序列。

## 决策

1. 房天下为主数据源（城市/区县/小区/房源/相册），链家榜按小区名匹配补在售/在租/关注数，匹配不到的小区以 `L` 前缀 id 独立收录。
2. 历史趋势不依赖第三方：采集器每次运行把均价追加进 `data/history.json`（同日覆盖），GitHub Actions 每日 cron 提交，趋势逐日累积；少于 2 个数据点时前端显示空态，不造数。
3. 链家补充小区（`L` 前缀）抓房源走 `?keyword=<名称>` 并按房源卡片上的小区名字段过滤，避免无效 projcode 拿到全市默认列表。

## 后果

- 数据口径以房天下为准（江北/渝北在房价地图中并入两江新区等区县，共 37 区）。
- 房源图片依赖 soufunimg 外链直出（已实测无 referer 限制）；若站方收紧防盗链，需改为代理或转存。
- 抓取为礼貌性爬取（UA、延迟、并发上限 3），站方改版会破坏解析器——解析失败时城市页 fail-fast 报错，其余字段留空不影响已有历史。
